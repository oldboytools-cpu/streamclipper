# Private cloud web workspace

This deployment runs the repository's existing StreamClipper dashboard as a private, single-owner web workspace.

## What it provides
- HTTPS termination by Render.
- Existing dashboard UI and processing pipeline.
- Persistent workspace, uploads, logs and rendered clips on a mounted disk.
- Strong generated bearer token with HttpOnly, SameSite=Strict and Secure cookie when behind HTTPS.
- CSRF origin validation that understands the trusted HTTPS reverse proxy.
- Public health check endpoint that returns only service status.

## Deploy
1. Connect the GitHub repository `oldboytools-cpu/streamclipper` to Render.
2. Create a Blueprint and choose `render.yaml`.
3. Wait for the Docker build and health check.
4. Open the service logs. The startup message prints the HTTPS URL with the access token.
5. Keep the token URL private. Anyone holding it can create jobs, upload media, change settings and access clips.

## Runtime notes
- This blueprint selects a paid CPU instance and 20 GB persistent disk. Render pricing and availability can change; review the current estimate before provisioning.
- The worker uses CPU Faster-Whisper and FFmpeg. GPU acceleration is not included. Long VODs may be slow and large files may exceed disk or memory limits.
- The app is single-owner. Do not use it as a public multi-user SaaS. Multi-user production requires account auth, per-user storage isolation, quotas, durable distributed jobs, abuse controls and security review.
- App-store mobile builds are not included in this web deployment.
- Only process media you own or are authorized to use, and comply with platform terms.

## Security controls
- `STREAMCLIPPER_ACCESS_TOKEN` is generated by Render's Blueprint system; do not replace it with a short or guessable value.
- The token-bearing startup URL is written to service logs. Restrict log access and do not paste the link into public chats.
- The app trusts `X-Forwarded-Proto` only because `STREAMCLIPPER_TRUST_PROXY=1` is set in this deployment and the app is intended to sit behind Render's proxy.
- The persistent disk contains uploaded source media, transcripts, generated clips, project state and settings. Treat backups and disk access as sensitive.
